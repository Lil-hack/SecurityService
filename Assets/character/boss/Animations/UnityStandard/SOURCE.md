# Unity locomotion animations

Source: https://github.com/Unity-Technologies/Standard-Assets-Characters
Original directory: Assets/_Standard Assets/Characters/Animation/Male/

Imported only the source rig and the Idle, WalkForwards, RunForwards,
StandingJump_Frame01 and Falling FBX files with their original importer metadata.
No legacy controller scripts or project dependencies are imported.

Copyright Unity Technologies. See LICENSE.md for the original Unity Companion
License notice. These assets are used in this Unity project.

Local clip settings bake root motion into the pose and remove external animation
events. Movement is provided by OfficeThirdPersonController; TripoLocomotion uses
the character's Humanoid Avatar to retarget these animations.
