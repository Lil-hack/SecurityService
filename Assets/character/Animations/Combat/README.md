# Alternating punches

Source: Quaternius Universal Animation Library Standard, CC0 1.0.
https://quaternius.com/packs/universalanimationlibrary.html
Author-hosted download mirror: https://opengameart.org/content/universal-animation-library
The original license is included in License.txt.

QuaterniusCombat.fbx contains the original animation library. The player uses
Punch_Jab and Punch_Cross, retargeted as Humanoid on the upper-body Punches layer.
Root motion and leg animation are excluded from this layer.

Left click with empty hands performs a punch. Repeated clicks or holding left
click alternate jab and cross. Holding an object keeps the existing charged throw
controls. Laptop interaction, disabled controls and focus loss cancel punching.

Setup: Tools / Office / Setup Alternating Punches.
Play Mode check: Tools / Office / Validate Alternating Punches.
